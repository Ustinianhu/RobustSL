# Open Science Appendix

## Artifact Availability

This artifact contains the source code, configurations, scripts, summarized experimental results, and plotting utilities needed to evaluate the GTSRB experiments of RobustSL. The artifact is intended for academic review, reproducibility checks, and follow-up research.

## Included Artifacts

- RobustSL implementation for split learning on GTSRB.
- GTSRB-specific model architectures and split-learning utilities.
- GTSRB backdoor attack and evaluation code.
- Experiment drivers for client-count studies and eta/k ablations.
- Summarized experiment outputs and publication-style figures.
- GTSRB configuration files and IID-variation configuration files.

## Dataset Scope

Only GTSRB-related data artifacts are provided. Other datasets used during development or exploratory experiments, including MNIST, FMNIST, CIFAR-10, and CIFAR-100, are not included in this artifact package.

The GTSRB training archive is larger than GitHub's normal repository blob limit, so it is distributed as a release asset rather than committed directly into the repository. See `data/GTSRB_DATA.md` for file names, placement, and SHA-256 checksums.

## Excluded Artifacts

Runtime logs, `__pycache__` directories, downloaded non-GTSRB datasets, model checkpoints, and temporary experiment folders are excluded to keep the artifact compact and reviewable. These files are regenerated by the provided scripts.

## Reproducibility Notes

The primary experiment is controlled by `Defense/configs/gtsrb.yaml` and command-line arguments. The code reports Main Task Accuracy / Clean Accuracy, Unseen Accuracy, and Attack Success Rate / Backdoor Accuracy after each communication round.
